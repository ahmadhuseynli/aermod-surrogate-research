# Disclaimer

This repository documents an independent atmospheric-dispersion research project.

AERMOD is the reference/teacher model used in the experiments. The surrogate described here is not an approved regulatory substitute for AERMOD, and nothing in this repository should be read as a recommendation to bypass required regulatory modelling.

The reported results belong to the restricted experimental domain described in the project documents. They should not be carried over to other sites, source types, terrain regimes or regulatory decisions without new validation.
