## v0.1.0 — 17 September 2026

First public archive of the private research project.

The underlying work had been running since 14 August 2026. This release did not mark the start of the research; it was the point at which the first development cycle was cleaned up for public inspection.

It included the 2018/2019 frozen temporal-validation results, meteorological-independence checks, research history, known failures, limitations, a technical note and the GitHub Pages site.

Large teacher data, model weights and the private operational lab were deliberately left out.
