# Evidence and provenance

## Public evidence level

This repository is a public research summary, not the full laboratory archive.

The private project retains:

- teacher outputs and run manifests;
- model and data hashes;
- frozen experiment decisions;
- run-by-run operational history;
- pre-truth validation seals;
- failure and recovery records;
- detailed implementation code and model assets.

The public release contains only the information needed to understand the research question, methods, reported results and limits.
